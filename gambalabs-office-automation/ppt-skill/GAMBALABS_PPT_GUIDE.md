# 감바랩스 PPT 제작 가이드 (에이전트용)

이 문서는 Codex/Claude 등 **에이전트가 감바랩스 브랜드 PPT를 자동 제작**할 때 따르는 규칙이다.
핵심 원칙: **LLM은 "무슨 내용을 어떤 레이아웃에 담을지"를 판단하고, 실제 렌더링은 `pptxgenjs`로 결정적으로 그린다.** 매번 같은 틀에 내용만 갈아끼우지 말고, **내용에 맞는 레이아웃을 선택**하되 브랜드 규격(색·폰트·모티프)은 항상 지킨다.

---

## 0. 준비물 (이 폴더에 포함)

| 경로 | 내용 |
|---|---|
| `theme/gambalabs_theme.md` | 브랜드 테마 원본 명세(색·폰트·레이아웃·모티프) |
| `assets/logo/` | `logo_color.png`, `logo_white.png`, `icon_color.png`, `icon_white.png` (SVG에서 생성됨) |
| `assets/backgrounds/` | `bg_cover.png`(표지 방사형+사운드링), `band.png`(헤더 밴드 그라데이션) |
| `scripts/gen_logo.js`, `scripts/gen_backgrounds.py` | 자산 재생성용(로고 SVG·색 바뀌면 실행) |
| `examples/build_samples.js` | **레퍼런스 pptxgenjs 스크립트** — 표지+적응형 스탯 슬라이드 패턴 |
| `examples/gambalabs_samples.pptx` | 승인된 샘플 결과물(눈으로 목표 확인용) |

의존성: Node + `pptxgenjs`, `@resvg/resvg-js` (로고), Python + `Pillow`(배경). 자산이 이미 있으면 재생성 불필요.

---

## 1. 워크플로우

1. **입력 파악.** 사용자가 준 문서(md/txt/docx/pdf, 또는 Polaris/OfficeCLI로 파싱된 JSON)를 읽고, 슬라이드 흐름(표지→목차→본문 N→마무리)으로 **내용을 구조화**한다. 목적에서 벗어나거나 사소한 내용은 빼고 간결화한다.
2. **테마 적용.** `theme/gambalabs_theme.md`의 색·폰트·레이아웃을 그대로 쓴다(아래 2절에 핵심 요약). 디자인 질문은 하지 않는다 — 테마가 이미 확정본이다.
3. **슬라이드별 레이아웃 선택(중요).** 각 슬라이드 내용의 성격에 맞는 레이아웃을 고른다(3절 참조). 전부 "제목+불릿"으로 만들지 말 것.
4. **렌더링.** `examples/build_samples.js`를 패턴 삼아 `pptxgenjs` 스크립트를 작성해 `.pptx`를 생성한다(4절 규칙 준수).
5. **검증.** 구조 검증 + 내용 검증(5절). 통과하면 사용자에게 전달.

## 2. 브랜드 테마 핵심 (원본: `theme/gambalabs_theme.md`)

- **비율**: 16:9 = `LAYOUT_WIDE` (13.333 × 7.5 inch)
- **컬러(‘#’ 없이 사용)**:
  | 용도 | Hex |
  |---|---|
  | 히어로 네이비(표지·마무리 배경, 큰 숫자) | `123979` |
  | 브랜드 네이비(흰 바탕 위 제목/강조) | `0038A3` |
  | 미디엄 블루(콜아웃 기본) | `1970AE` |
  | 딥 박스 네이비(강조 박스) | `153C7E` |
  | 본문 바탕(살짝 회색) | `ECECEC` |
  | 화이트 | `FFFFFF` |
  | 뮤티드 라이트(네이비 위 보조텍스트) | `C9D4E8` |
  | 서브 그레이(흰 바탕 위 보조) | `5A6472` |
- **폰트**: 제목 `HY견고딕`(bold), 본문 `맑은 고딕`. 크기: 표지 대제목 40 / 본문 헤더 28~30 / 큰 숫자 40 / 본문 15~16 / 캡션 12~13pt.
- **반복 모티프**: ①로고 막대 아이콘(표지·마무리=워드마크, 본문=좌상단 아이콘) ②우측 아치 기둥(표지=라이트그레이, 마무리=네이비 반전) ③상단 헤더 밴드(가로 그라데이션+흰 제목) ④라운드 콜아웃 박스 ⑤큰 숫자 강조 ⑥사운드 링(표지 배경).
- **페이지 필수 구성**: 표지 · 목차 · 본문 · 마무리.

## 3. 슬라이드 유형별 레이아웃 (내용에 맞게 선택)

| 내용 성격 | 추천 레이아웃 |
|---|---|
| 통계·핵심 수치 | **큰 숫자 스탯 카드**(40pt 히어로네이비 숫자 + 라벨). `build_samples.js` 2번 슬라이드 참조 |
| 3~4개 병렬 항목 | 카드 N열(라운드 박스, 인덱스 뱃지) |
| 비교(전/후, 장/단) | 2열 대비 |
| 절차·흐름 | 번호 스텝 + 화살표 |
| 표 데이터 | 헤더행 네이비 배경, 본문행 흰 배경 표 |
| 서술형 개요 | 헤더밴드 + 좌측 요지 문장 + 우측 도식/아이콘 |

- **표지**: `bg_cover.png` 전체 배경 → 우상단 `logo_white.png` → 좌측 대제목(HY견고딕 40 화이트) + 부제 → 좌하단 발표자 블록. 우측 아치 기둥(라이트그레이 반투명).
- **본문**: 배경 `ECECEC` → 상단 `band.png`(y0, h≈1.05, 세로 1/6 이하) → 밴드 좌상단 `icon_white.png` → 밴드 위 제목(흰색 가운데) → 본문 영역 y1.4부터.
- **마무리**: 배경 `ECECEC` → 우측 네이비 아치 기둥 → "감사합니다." (브랜드네이비) + 태그라인 → 좌하단 연락처, 우상단 `logo_color.png`.

## 4. pptxgenjs 필수 규칙 (어기면 파일 깨짐)

- `pres.layout = "LAYOUT_WIDE"` 를 슬라이드 추가 **전에** 설정.
- **색은 `#` 금지, 8자리 금지**: `color: "123979"`. 투명도는 `transparency: 0-100`(채움), `opacity`(그림자)로.
- 옵션 객체(shadow 등)를 **재사용하지 말 것** — 매번 새로 생성(pptxgenjs가 in-place 변형).
- 그림자 `offset`은 **≥ 0**. 위쪽 그림자는 `angle: 270`.
- 리스트: 각 항목 `bullet: true`(리터럴 `•` 금지), 마지막 제외 `breakLine: true`, 문단 간격은 `paraSpaceAfter`.
- `rectRadius`는 `ROUNDED_RECTANGLE`에서만.
- **그라데이션 채움 미지원** → 배경은 준비된 PNG(`bg_cover.png`/`band.png`) 사용.
- 도형과 텍스트를 같은 x에 맞추려면 텍스트박스 `margin: 0`.
- 배경 이미지: `slide.background = { path: ".../bg_cover.png" }`, 단색은 `{ color: "ECECEC" }`.
- **금지(‘AI 티’ 나는 요소)**: 제목 밑줄, 장식용 컬러 바/사이드 스트라이프, 텍스트 넘침, 본문 가운데정렬(제목만 가운데).

## 5. 검증 (필수)

```bash
# 구조 검증 (pptx 스킬 동봉 스크립트)
python <pptx-skill>/scripts/office/validate.py output.pptx
# 내용 검증
markitdown output.pptx   # 누락·오타·순서 확인
```
- 텍스트 넘침/박스 이탈, 요소 겹침, 여백(≥0.5") 위반, 저대비를 점검.
- 폰트(HY견고딕/맑은고딕)는 실제 PowerPoint에서 정상 표시되나, LibreOffice 미리보기에선 대체되어 폭이 달라 보일 수 있음 — 넘침 판단은 실제 PowerPoint 기준.
