# 발표자료 테마 파일 작성 가이드 (skill용)

감바랩스 오피스 AI의 **PPT 테마**를 직접 만들어 앱에 업로드할 수 있다.
이 문서는 Claude/Codex 등 에이전트가 **테마 `.json` 파일을 스킬로 생성**할 때의 스키마다.
(앱: 발표자료 탭 → 🎨 디자인 테마 옆 `＋` → "파일 업로드"로 이 json을 넣으면 즉시 적용)

## 동작 원리
테마는 `render_deck.js`가 슬라이드를 그릴 때 쓰는 **색·폰트·밴드/표지/마무리 스타일** 설정이다.
업로드된 커스텀 테마는 브랜드 이미지 에셋이 없으므로 **도형 기반(useImages=false)** 으로 강제되고,
누락 필드는 앱이 팔레트(C)에서 자동 보정한다. 따라서 **최소한 `label`과 `C`만 있어도** 동작한다.

## 최소 예시
```json
{
  "label": "우리팀 블루",
  "desc": "밝은 배경 · 블루 포인트",
  "C": {
    "hero": "1B3A6B",
    "brand": "2563EB",
    "body": "F5F8FF",
    "cardInk": "1B3A6B"
  }
}
```

## 전체 스키마
```json
{
  "label": "테마 표시 이름(필수)",
  "desc": "선택 목록에 뜨는 설명",
  "C": {
    "hero":   "큰 숫자·본문 제목 색 (진한 색 권장)",
    "brand":  "강조·포인트·차트 1번 색",
    "med":    "차트 2번/보조 (생략 시 brand 밝게)",
    "body":   "슬라이드 배경색",
    "white":  "FFFFFF",
    "muted":  "표지 부제 등 보조 텍스트",
    "gray":   "캡션·설명 회색",
    "sky":    "차트 3번 색",
    "teal":   "차트 보조 색",
    "surface2":"이미지 자리표시 배경",
    "cardBg": "카드/박스 배경 (밝은 테마=FFFFFF)",
    "cardInk":"카드 안 텍스트 색"
  },
  "F": { "title": "제목 폰트(예: 맑은 고딕)", "body": "본문 폰트" },

  "bandColor": "상단 헤더 밴드 색",
  "bandInk":   "밴드 위 제목 색",
  "bandLine":  "(밝은 밴드일 때) 밴드 하단 구분선 색",
  "coverBg":   "표지 배경색",
  "coverInk":  "표지 대제목 색",
  "coverSub":  "표지 부제 색",
  "coverFoot": "표지 하단 발표자 색",
  "closingBg": "마무리 배경색",
  "accent":    "표지/마무리 포인트 바 색"
}
```

## 규칙
- 색은 **`#` 없이 6자리 hex** (`"2563EB"`). 3자리(`"25E"`)도 허용되나 6자리 권장.
- `useImages`, `logo`는 무시된다(커스텀은 항상 도형 기반). 감바 브랜드 이미지 밴드/로고가 필요하면 내장 "감바랩스 네이비" 테마를 쓸 것.
- 대비를 지켜라: `body`(배경)와 `hero`/`cardInk`(텍스트)는 명도 차가 커야 읽힌다. 밝은 배경엔 진한 텍스트.
- `bandColor`를 진하게 두면 밴드 위 `bandInk`는 흰색(`FFFFFF`)으로.

## 앱에서 색만으로 만들기(파일 없이)
`＋ → 직접 제작`에서 **배경·강조·텍스트 3색 + 밴드 옵션**만 고르면 앱이 위 전체 설정을 자동 생성한다.
세밀한 팔레트 제어가 필요할 때만 이 json 파일을 직접 작성해 업로드하면 된다.
