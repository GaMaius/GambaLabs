# 감바랩스(Gamba Labs) 기본 테마

> 이 파일 하나를 다음 세션에 업로드하면, 디자인 질문 없이 이 스타일을 그대로 적용해 PPT를 만든다.
> 함께 보관/업로드하면 좋은 파일: **로고 원본 `gambalabs-logo-bk-30.svg`** (아래 로고 자산 재생성에 필요).

---

## 1. 기본 규격

- **비율:** 16:9 (와이드). pptxgenjs 기준 `13.333 × 7.5 inch` (`LAYOUT_WIDE`).
- **용도:** 제품·서비스 소개용 발표자료.
- **톤:** 화이트 바탕 + 딥네이비/블루 포인트. 심플·모던·테크. 텍스트 최소, 도식·아이콘 위주.

## 2. 컬러 팔레트 (hex, `#` 없이 사용)

| 이름 | Hex | 용도 |
|---|---|---|
| 히어로 네이비 | `123979` | 표지·마무리 배경, 본문 큰 숫자·핵심 강조 텍스트 |
| 브랜드 네이비 | `0038A3` | 로고 워드마크, 흰 바탕 위 제목/강조 |
| 미디엄 블루 | `1970AE` | 콜아웃(라운드 박스) 기본 채움 |
| 딥 박스 네이비 | `153C7E` | 진한 콜아웃 박스(본문 강조 박스) |
| 본문 바탕 | `ECECEC` | 본문·마무리 슬라이드 배경(순백 아님, 살짝 회색) |
| 화이트 | `FFFFFF` | 네이비/밴드 위 텍스트, 표지 제목 |
| 뮤티드 라이트 | `C9D4E8` | 네이비 위 보조 텍스트(발표자·날짜 등) |
| 서브 그레이 | `5A6472` | 흰 바탕 위 보조 설명 텍스트 |

**로고 그라데이션(막대 아이콘):** `003899` → `0069B7` → `2390D4` → `20AEE5` (딥네이비→시안, 좌→우).
색 지배 원칙: 화이트/라이트그레이가 바탕(60~70%), 네이비가 주 포인트, 블루~시안이 보조.

## 3. 폰트

- **제목:** `HY견고딕` (bold). 표지 대제목·본문 헤더·큰 숫자.
- **본문:** `맑은 고딕`. 불릿·설명·캡션.
- 대표 크기: 표지 대제목 40pt / 표지 부제 24pt / 본문 헤더 제목 30pt / 큰 숫자 40pt / 본문 불릿 16pt / 캡션 12~13pt.
- ※ 리눅스 미리보기에는 두 폰트가 없어 대체 렌더된다. 검수는 폰트 모양이 아니라 레이아웃·여백·넘침 기준으로 한다. 실제 파워포인트에서는 정상 표시.

## 4. 배경 방식 (이미지로 재생성)

pptxgenjs는 그라데이션 채움을 지원하지 않으므로 아래 배경은 **PNG로 미리 만들어** 슬라이드 배경/상단에 넣는다. 해상도 1920×1080 기준.

- **표지 배경 `bg_cover.png`** (딥네이비 + 은은한 사운드 링):
  - 베이스 `123979`, 모서리로 갈수록 `0B2656`로 어두워지는 방사형(중심 화면의 상단-우측 약 62%,42%).
  - 그 위에 **동심원(사운드 웨이브) 링**을 매우 옅게(밝기 ~22/255, 가우시안 블러 2, 밝은 청색 `78A0DC` 합성) 중심 (60%,55%)에서 반경 120~900px, 간격 70px로. 음성인식 정체성을 상징하는 모티프.
- **마무리 배경 `bg_closing.png`:** 단색 `ECECEC` (아치는 배경이 아니라 도형으로 그림, 아래 6-마무리 참조).
- **헤더 밴드 `band.png`** (본문 상단 띠, 1920×170): **가로 그라데이션** 좌 `3D6EA2`(슬레이트블루) → 우 `60A4C8`(스카이블루).
- 본문 바탕 자체는 이미지 없이 `slide.background = { color: "ECECEC" }`.

> 그라데이션 변화 원칙: 표지는 방사형+링, 헤더는 가로형으로 형태를 달리해 단조로움을 피한다. 농도는 은은하게.

## 5. 로고 자산 (원본 SVG에서 PNG로 재생성)

원본 `gambalabs-logo-bk-30.svg`(viewBox `0 0 245 30`, 워드마크=브랜드 네이비 `0038A3`, 아이콘=위 그라데이션)에서 cairosvg로 뽑는다.

- `logo_color.png` — 원본 그대로(그라데이션 아이콘 + 네이비 워드마크). **흰/밝은 바탕**용.
- `logo_white.png` — 모든 `fill`/`stop-color`를 흰색으로 치환. **네이비 바탕**(표지)용.
- `icon_color.png` — viewBox를 `0 0 46 30`으로 잘라 막대 아이콘만(컬러).
- `icon_white.png` — 아이콘만 흰색. **헤더 밴드**(블루) 위 좌상단용.
- 슬라이드 삽입 시 원본 비율 유지: 전체 로고 가로:세로 ≈ **8.16:1**, 아이콘 ≈ **1.53:1**.

## 6. 외곽 여백 & 페이지별 레이아웃 (13.333×7.5 기준, 단위 inch)

**공통 외곽 여백:** 좌우 약 `0.7~0.9`, 상하 `0.4` 이상. 모든 요소를 이 보이지 않는 외곽선 안에 정렬.

### 표지 (딥네이비)
- 배경: `bg_cover.png` 전체.
- **우측 아치 기둥:** `roundRect` x`9.55` y`3.05` w`1.95` h`5.0` `rectRadius 0.97`, 채움 `EAEAEA` `transparency 12`, 선 없음. (바닥이 슬라이드 밖으로 나가 위만 둥근 기둥 형태.)
- **로고(화이트):** `logo_white.png` 우상단 x`10.05` y`0.42` w`2.55`.
- **대제목:** `HY견고딕` 40pt bold 화이트, 좌측 x`0.9` y`2.35`. 그 아래 부제 24pt 화이트.
- **발표자 블록(좌하단):** 이름 15pt 화이트 / 직함 13pt·날짜 12pt `C9D4E8`, x`0.92` y`5.85`.
- 표지에는 내용에 어울리는 이미지를 넣는다(저작권 사진·실존 인물은 피하고 식별 안 되는 일러스트·추상 모티프 사용). 기본 사운드 링 배경이 그 역할을 겸한다.

### 목차
- 본문 레이아웃(헤더 밴드) 사용. 제목 "목차". 각 페이지 제목을 20자 이내로 간략히, 세로 나열 또는 2열. 번호/아이콘은 브랜드 블루 계열.

### 본문
- 배경 `ECECEC`.
- **헤더 밴드:** `band.png` x`0` y`0` w`13.333` h`1.05` (세로의 약 1/7, 규칙상 1/6 이하 유지).
- **밴드 위 제목:** `HY견고딕` 30pt bold 화이트, 슬라이드 전폭 가운데 정렬·수직 중앙.
- **좌상단 아이콘:** `icon_white.png` x`0.4` y`0.3` w`0.72`.
- 본문 영역은 밴드 아래 y`1.4`부터. 텍스트 최소화, 도식·아이콘·일러스트 활용.
- **콜아웃 박스:** `roundRect` `rectRadius 0.14`, 채움 `1970AE`(기본) 또는 `153C7E`(강조), 선 없음. 안의 불릿 텍스트는 화이트 16pt, `margin 4`, 상하좌우 여백 충분히, 수직 중앙.
- **큰 숫자 패턴:** 히어로 네이비 `123979` 40pt bold, 오른쪽의 콜아웃 박스와 한 행으로 정렬(숫자 폭 ~1.5, 박스 폭 ~5.85, 행 높이 ~1.35, 행 간격 ~0.22).
- 불릿은 `bullet: true`(리터럴 `•` 금지), 항목마다 `breakLine`, 문단 간격은 `paraSpaceAfter`.

### 마무리
- 배경 `ECECEC`.
- **우측 아치 기둥(네이비 버전):** `roundRect` 위만 둥근 기둥, 채움 `103E90`(딥네이비), 우측 배치(표지 아치의 컬러 반전).
- **대문구:** "감사합니다." `HY견고딕` 대형(≈54pt) bold 브랜드 네이비 `0038A3`, 좌측.
- 그 아래 태그라인(예: "음성인식기술로 더 안전하고, 더 편리한 세상을 만듭니다.") `맑은 고딕` 회색.
- 좌하단: 연락처/링크(`Demo:`, `Contact:`) + 필요 시 QR. 우상단 `logo_color.png`.

## 7. 반복 시각 모티프

1. **로고 막대 아이콘** — 표지·마무리는 워드마크 포함 로고, 본문은 좌상단 아이콘만.
2. **우측 아치(기둥) 도형** — 위만 둥근 세로 기둥. 표지=라이트그레이, 마무리=딥네이비(반전 대칭).
3. **상단 헤더 밴드** — 본문 슬라이드 공통. 슬레이트→스카이 가로 그라데이션 + 흰 제목.
4. **라운드 콜아웃 박스** — `rectRadius 0.14`의 블루 박스 안 흰 불릿.
5. **큰 숫자 + 박스** — 통계/핵심 수치 강조 패턴.
6. **사운드 링** — 음성 AI 정체성. 표지 배경의 옅은 동심원.

## 8. 필수 페이지 구성

표지 · 목차 · 본문 · 마무리를 모두 포함. 본문은 줄글 대신 도식·숫자·아이콘·일러스트로 전달.

## 9. 제작 파이프라인 메모

- pptxgenjs로 생성, hex는 `#` 없이·8자리 금지. `roundRect`에서만 `rectRadius`.
- 그라데이션(표지 배경·헤더 밴드)은 PIL로 PNG 생성 후 삽입.
- 로고는 SVG→cairosvg로 컬러/화이트·전체/아이콘 4종 PNG 렌더.
- 생성 후 `validate.py`로 검증, LibreOffice→PDF→이미지로 육안 검수(여백·넘침·정렬).
