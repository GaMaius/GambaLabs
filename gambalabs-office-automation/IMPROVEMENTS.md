# 개선 과제 체크리스트

작업을 하나씩 처리하며 체크. (기록: 2026-08-03)

## 1. 첫 사용자 온보딩 — 사용법 이해·진입장벽 낮추기
> 처음 쓰는 사람이 뭘 어떻게 해야 할지 어려움. **구체안 미확정.**

후보 방향:
- [ ] 발표자료 모드별(테마 개발 / 내용 PPT 입력 / 풀 로딩)로 **가이드·설명** 노출
- [ ] PPT 제작 시 선택지를 **질문형 대신 "항목"으로 미리 노출** — `pptx-making-guide` skill의 질문 항목들(비율·컬러·배경·폰트·참고자료 등)을 UI 항목으로.
  - [ ] 각 항목을 누르면 **선택지가 펼쳐짐** (예: 참고자료 → 파일 업로드, 테마색 → 컬러 입력 등 형식에 맞게)
- [ ] 처음 진입 시 **간단한 온보딩/투어**(선택)

## 2. 편집 UX — floating 도구 또는 PPT 임베드 편집
> 결과물을 앱 안에서 바로 손보기 어렵다.

후보 방향:
- [ ] **floating 오버레이**(캡쳐/메모 편집 AI처럼) 상태로 웹/화면 위에서 사용
- [ ] 또는 **생성된 PPT를 앱에 임베드**해서 그 자리에서 편집
- [ ] 방식 결정 필요(둘은 구현 난이도·방향이 크게 다름)

## 3. 인수인계(hand-over) 문서 — Word(.docx)

- [ ] 프로젝트 개요·구조·실행·설계방침·백로그를 담은 **Word 인수인계 문서** 작성
- [ ] 형식: **.docx**
