후보 방향:
- [x] 처음 진입 시 **온보딩 가이드 모달** — 3탭·발표자료 4모드·"디자인은 테마로 결정" 안내. 사이드바 ❓ 버튼으로 재열람, '다음부터 안 열기' 옵션. (1단계 완료)

- [ ] PPT 제작 시 선택지를 **질문형 대신 "항목"으로 미리 노출** — `pptx-making-guide` skill의 질문 항목들(목적·비율·컬러·배경·폰트·참고자료 등)을 UI 항목으로.
  - [ ] 각 항목을 누르면 **선택지가 펼쳐짐** (예: 참고자료 → 파일 업로드, 테마색 → 컬러 입력, 비율 → 16:9/A4/4:3 등, "기타 자유입력" 포함)
